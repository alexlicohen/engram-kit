# Example project — dossier

A dossier is a cross-cutting one-pager that synthesises many event notes into current state. It is
reconciled (not rewritten) as new notes arrive: `/engram-dossiers` folds in notes newer than
`updated:` through `scripts/reconcile_dossier.py`. FICTIONAL seed.
